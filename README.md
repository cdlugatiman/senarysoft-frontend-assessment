# Senarysoft Front-End Assessment

A responsive recreation of the **User Management - Edit Users** interface for the Senarysoft LLC Front-End Developer Practical Assessment.

## Requirements

See [`CLAUDE_TASK.md`](CLAUDE_TASK.md) for the complete assessment implementation specification.

## Reference

The supplied assessment reference is stored at:

`assets/reference-user-management.png`

## Intended stack

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript

No backend or database is required.

## How to run

The finished assessment should be runnable as a static frontend.

For local development, open `index.html` directly in a browser or serve the folder with any simple static web server.

Example with Python:

```bash
python -m http.server 8000
```

Then open:

`http://localhost:8000`

## Features to implement

- Responsive enterprise dashboard layout
- User management sidebar
- Search and search-by-field
- Status, region, and division filters
- Clear filters
- Pagination
- Add user
- Edit user
- Enable/disable user
- Mock user data
- Responsive desktop/tablet/mobile behavior

## Notes

The implementation should remain simple and understandable because the candidate may be asked to explain or modify the work during a follow-up interview.
